# Local icon assets

The SVGs in this directory are bundled locally so the portfolio does not depend on a third-party icon CDN.

- `social-*.svg` and `hobby-*.svg` use Bootstrap Icons (MIT), locally tinted for readability. See `licenses/LICENSE-BOOTSTRAP-ICONS.txt`.
- `facebook.svg`, `instagram.svg`, `linkedin.svg`, `github.svg`, `git.svg`, `x.svg`, `tiktok.svg`, `pinterest.svg`, `roblox.svg`, `html5.svg`, `css.svg`, `javascript.svg`, `postgresql.svg`, and `python.svg` use Simple Icons marks (CC0-1.0). See `licenses/LICENSE-SIMPLE-ICONS.txt`.
- `canva.svg`, `cplusplus.svg`, and `mysql.svg` use Devicon marks (MIT). See `licenses/LICENSE-DEVICON.txt`.
- `microsoft-word.svg`, `microsoft-powerpoint.svg`, and `microsoft-excel.svg` use Material Design Icons marks, with application-brand colors (Apache-2.0). See `licenses/LICENSE-MATERIAL-DESIGN-ICONS.txt`.

The page uses a local Roblox mark; the other requested game titles are text-first labels rather than guessed or scraped artwork. Product and platform names/logos are used only for identification. Trademarks belong to their respective owners.
